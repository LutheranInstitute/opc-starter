# >_æ^æ://#opc · 一人公司 starter

**One person. Many agents. One company.** · 一个人，一群智能体，一家公司。

## 3 steps · 三步
1. **Use this template** → your own repo. 使用此模板，建立你自己的仓库。
2. Edit **`ae.json`**: name, handle, offers. 编辑 `ae.json`。
3. Settings → Pages → `main` / root. Your node is live at `https://<you>.github.io/<repo>/`. 开启 GitHub Pages。

Then claim your address in the open registry: https://lutheraninstitute.github.io/aeee-lab/lab/opc/claim/

## Files
- `index.html` renders your node from `ae.json` (Chinese / English).
- `ae.json` is your agent-readable manifest (`ae.manifest/0.1`).
- `llms.txt` tells agents how to read you and how to propose work.

## Rules
- Evidence ≠ Authority: agents propose, you approve.
- Forking gives you an environment, never anyone else's authority or credentials.
- Affiliate links are marked as such.
